# FlipGoal: Football Pinball - Privacy Policy

Published by Nuco Games.

This page is generated from the in-game privacy policy text, so the store page and
the in-game screen always show the same wording.

- Page: `index.html` (single file, no external resources)
- Source of truth: `godot/assets/ui/ekran/gizlilik.json` -> `gizlilik_metni` in the game project

## Updating

Edit the text in the game project, then re-run the factory command:

```
gizlilik_sayfasi.py yayinla <project> --kaynak godot/assets/ui/ekran/gizlilik.json --anahtar gizlilik_metni
```

Do not edit `index.html` by hand; the next run overwrites it.
